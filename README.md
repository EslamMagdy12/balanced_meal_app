# 🥗 Balanced Meal App

A Flutter mobile application that helps users build a nutritionally balanced meal by selecting food items across three categories — vegetables, meats, and carbs — tailored to their personal daily calorie target.

---

## 📱 Features

- **Calorie Calculator** — Users enter their gender, weight, height, and age; the app uses the Harris-Benedict formula to compute their required daily calorie intake.
- **Food Selection** — Browse and pick items from three food categories (Vegetables, Meats, Carbs), each with calorie and price info.
- **Order Summary** — Review selected items with total calories and price before confirming.
- **Place Order** — Submit the final order to a remote backend.
- **Localization** — Full Arabic and English support (with RTL layout for Arabic).
- **Splash Screen** — Native splash screen generated with `flutter_native_splash`.
- **Offline Error Handling** — Friendly, localized messages for all network failure scenarios.

## 🏗️ Architecture

The project follows a **feature-first clean architecture** pattern, separating concerns across three layers inside each feature:

```
lib/
├── core/                         # Shared infrastructure
│   ├── assets/                   # Colors, image paths, lottie paths
│   ├── base/                     # BaseState sealed class hierarchy
│   ├── theme/                    # AppTheme (Poppins font, orange brand color)
│   └── utils/
│       ├── datasource_execution/ # ApiManager, ApiResult, ApiException, DioModule
│       ├── di/                   # Dependency injection (GetIt + Injectable)
│       ├── dialogs/              # AppDialogs, AppToast
│       ├── l10n/                 # Auto-generated LocaleKeys
│       ├── logging/              # Logger module
│       ├── routes/               # RouteName constants, AppRoute generator
│       └── validator/            # Form validators
│
├── features/
│   ├── welcome/                  # Welcome / landing screen
│   ├── user_details/             # User detail form + calorie calculation
│   └── order/
│       ├── presentation/         # Screens, widgets, OrderCubit, OrderState
│       ├── domain/               # FoodEntity, OrderRepo contract, use cases
│       └── data/                 # DTOs, Firestore data source, Retrofit client, RepoImpl
│
├── balanced_meal_app.dart        # Root MaterialApp
├── firebase_options.dart         # FlutterFire-generated Firebase config
└── main.dart                     # Entry point — init Firebase, DI, localization
```

### Navigation flow

```
WelcomeScreen
    └─► UserDetailsScreen  (enter gender / weight / height / age)
            └─► OrderScreen  (browse & select foods; calorie target passed as argument)
                    └─► OrderSummaryScreen  (review → confirm → place order)
```

## 🌍 Localization

Translations live in `assets/translations/`:
- `en.json` — English
- `ar.json` — Arabic

Locale keys are auto-generated into `lib/core/utils/l10n/locale_keys.g.dart` via `easy_localization`.  
The user's last selected language is persisted with `shared_preferences`.

## ⚙️ Code Generation

Several files are generated by `build_runner` and should **not** be edited manually:

| Generated file | Generator |
|---|---|
| `*.g.dart` (DTOs) | `json_serializable` |
| `order_retrofit_client.g.dart` | `retrofit_generator` |
| `di.config.dart` | `injectable_generator` |
| `locale_keys.g.dart` | `easy_localization` |

Run generation with:

```bash
flutter pub run build_runner build --delete-conflicting-outputs
```

## 🚀 Getting Started

### Prerequisites

- Flutter SDK (stable channel)
- Java 17 (for Android builds)
- A Firebase project configured with Firestore (Android `google-services.json` and iOS `GoogleService-Info.plist` already included)

### Install & run

```bash
flutter pub get
flutter pub run build_runner build --delete-conflicting-outputs
flutter run
```
